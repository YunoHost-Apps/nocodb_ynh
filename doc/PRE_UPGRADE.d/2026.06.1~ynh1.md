#UPGRADE IS BROKEN FROM BEFORE v2026.06.1

Unfortunately, the support for MariaDB seems broken on NocoDB.

Here is the proposed course of action, since upgrading is not possible:

1. Log into the app, and export all available databases in JSON (or other) format
2. Make a dedicated backup of the app (better be safe than sorry)
3. Delete the app
4. Install the app to version 2026.06.1
5. Import the exported data
